# Task: Build a Simple Todo List

Create a small todo-list application that lets a user keep track of everyday tasks.

## Requirements

- Show all todo items.
- Add a todo with a non-empty title.
- Mark a todo as complete or incomplete.
- Delete a todo.
- Keep todos after the page is refreshed (local storage is sufficient).
- Present completed items differently from active items.

## Acceptance criteria

- Empty or whitespace-only todos cannot be added.
- Adding, toggling, and deleting a todo updates the list immediately.
- Refreshing the page preserves the current list and completion states.
- The app has a clear empty state when no todos exist.
- The main behavior is covered by a few focused tests.

## Nice to have

- Filter the list by all, active, or completed items.
- Clear all completed items with one action.
